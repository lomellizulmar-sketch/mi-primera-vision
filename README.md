# mi-primera-vision

Documentar mis ideas para el diseño de mi emprendimiento.

## ♻️ Sobre el Emprendimiento (Upcycling Textil)
Este proyecto se enfoca en la transformación de prendas textiles, tanto nuevas como usadas en buen estado, para darles una segunda oportunidad de vida. A través del suprareciclaje (upcycling), aplicamos nuevos diseños y técnicas para crear productos únicos y reducir el desperdicio textil.

## 🎒 Productos y Accesorios
Las prendas se transformarán principalmente en:
* **Prendas rediseñadas**: Ropa modificada con nuevos estilos y cortes.
* **Bolsos**: Mochilas, carteras o bolsos más pequeños.
* **Accesorios**: Pulseras, pañuelos, elásticos para el cabello (scrunchies), y complementos para bolsos.

## 🎯 Objetivos del Proyecto
* Diseñar un catálogo inicial con los primeros prototipos de productos.
* Definir la identidad visual, el logotipo y los valores ecológicos de la marca.
* Establecer el proceso de recolección, selección y desinfección de las prendas textiles.
